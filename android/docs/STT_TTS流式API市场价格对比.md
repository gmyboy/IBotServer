## 五、选型建议

### 5.1 按场景推荐

| 场景 | 推荐厂商 | 理由 |
|------|---------|------|
| **国内ToC消费级产品（成本优先）** | 火山引擎（豆包2.0）/ 腾讯云 / 阿里云 | 中文好、延迟低、价格亲民、合规 |
| **国内高端/企业级产品（效果优先）** | 讯飞 / 火山引擎大模型版 / MiniMax | 识别准确率高、合成自然度好 |
| **出海/多语言产品** | Azure / Google Cloud / ElevenLabs | 多语言支持好、全球节点、稳定性高 |
| **极简MVP/快速验证** | 火山引擎 / 阿里云 | 开通快、文档全、免费额度足 |
| **高质量TTS为主（英语/多语种）** | ElevenLabs / Azure HD | TTS自然度行业顶尖 |
| **端到端实时语音对话** | OpenAI Realtime API / Azure Voice Live / 豆包端到端 | 一体化方案，延迟最低 |
| **私有化部署** | 讯飞 / 阿里云 / 火山引擎 | 均提供本地化部署方案 |

### 5.2 关键对比维度

| 维度 | 国内厂商优势 | 国外厂商优势 |
|------|------------|------------|
| **价格** | ✅ 国内厂商整体便宜30%~50% | ❌ 相对较贵（ElevenLabs STT/AWS TTS除外） |
| **中文效果** | ✅ 中文识别/合成效果显著更好 | ⚠️ 中文支持普遍不如国内厂商 |
| **延迟** | ✅ 国内节点延迟50~200ms | ❌ 海外节点延迟200~500ms+ |
| **合规性** | ✅ 数据在国内，符合等保要求 | ❌ 数据出境问题需评估 |
| **多语言** | ⚠️ 中文强，多语言较弱 | ✅ 多语言支持更全面 |
| **TTS自然度（英语）** | ⚠️ 进步快但仍有差距 | ✅ ElevenLabs/Azure/OpenAI自然度极高 |
| **并发成本** | ✅ 并发增购费用较低 | ❌ 并发成本较高 |
| **免费额度** | ✅ 新用户资源包慷慨 | ✅ AWS/Google永久免费层 |

### 5.3 成本优化建议

1. **资源包采购**：年付资源包通常比后付费便宜20%~50%，预估用量后购买
2. **分级使用**：简单场景用标准版/轻量版模型，复杂场景才用大模型
3. **并发控制**：合理设置并发数，避免浪费，高峰期可临时增购
4. **缓存复用**：TTS对常用回复进行缓存，避免重复合成
5. **VAD前置**：做好端点检测，减少无效音频上传，降低STT计费时长
6. **混合架构**：日常流量用便宜厂商，高峰期/高价值用户用高端厂商
7. **开源补充**：简单场景可考虑本地部署开源模型（Whisper/VITS/ChatTTS等）作为兜底或离线方案

## 七、价格说明与免责

1. **价格时效性**：本文档价格基于2026年7月公开资料整理，各厂商可能随时调整价格，请以官网最新定价为准。
2. **阶梯定价**：多数厂商采用阶梯定价，用量越大单价越低，文档中列出的是典型区间。
3. **隐藏成本**：除了基础API调用费，还需考虑：
   - 并发/QPS增购费用
   - 数据存储/日志费用
   - 网络流量费用（CDN/带宽）
   - 自定义模型训练费用
   - 技术支持/SLA费用
4. **汇率波动**：国外厂商价格以美元计价，实际人民币成本受汇率影响。
5. **免费额度**：大部分厂商为新用户提供免费试用额度，建议先测试效果再决定采购。
6. **效果差异**：价格不完全代表效果，建议根据自身业务场景做POC测试后再选型。
